# المعلم الذكي

منصة عربية تساعد الطلاب على حل المسائل من خلال رفع الصور أو التقاطها، مع اختيار الصف والسنة وتفسير الحل باستخدام الذكاء الاصطناعي.

## المميزات
- اختيار المرحلة: ابتدائي / إعدادي / ثانوي
- اختيار السنة حسب المرحلة
- رفع صورة أو استخدام الكاميرا
- شرح خطوة بخطوة للحل
- واجهة عربية ومريحة
- يدعم الذكاء الاصطناعي عند إضافة OPENAI_API_KEY

## التشغيل

1. انسخ المشروع:
   ```bash
   git clone https://github.com/mrshadowh/smart-teacher.git
   cd smart-teacher
   ```

2. تثبيت الحزم:
   ```bash
   npm install
   ```

3. تشغيل المشروع محلياً:
   ```bash
   npm run dev
   ```

4. اذهب إلى:
   ```text
   http://localhost:3000
   ```

## إعداد AI

أنشئ ملف `.env.local` وأضف:

```bash
OPENAI_API_KEY=your_key_here
```

## بنية المشروع

- `app/page.tsx` — الصفحة الرئيسية
- `app/api/analyze/route.ts` — نقطة تحليل الصور والحلول
- `app/globals.css` — تنسيق الموقع

## ملاحظة

النسخة الحالية تعمل كـ MVP تجريبي، وإذا لم يتم إضافة مفتاح OpenAI ستظهر إجابة نموذجية توضح الموضوع وتسمح لك باختبار الواجهة بشكل كامل.
